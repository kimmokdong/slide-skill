# 🧠 Text-to-Slide-Architect (슬라이드 스킬)

**"교사의 통찰력을 가장 빠르고 아름답게 시각화한다"**

사용자의 거친 텍스트 아이디어나 대본을 기승전결이 있는 풍부한 프레젠테이션으로 자동 생성하는 바이브코딩(Vibe-Coding) AI 코파일럿 스킬입니다. 텍스트를 분석하여 웹 기반의 아름다운 **HTML 슬라이드**와 발표용 **통이미지 와이드 PPTX**를 원클릭으로 추출합니다.

## 🚀 초보자를 위한 스킬 사용 가이드 (How to Use)

**"스킬(Skill)이 무엇인가요?"**
스킬은 AI 코파일럿(안티그래비티 등)이 특정 작업을 완벽하게 수행할 수 있도록 돕는 **'행동 지침서 및 도구 모음'**입니다. 이 슬라이드 스킬을 설치하면 AI가 단순한 챗봇을 넘어, 전문 프레젠테이션 디자이너처럼 문서를 기획하고 PPTX 파일까지 만들어내는 능력을 갖추게 됩니다.

### 1. 사전 준비사항 (Prerequisites)
이 스킬이 원활하게 작동하려면(PPTX 추출, 다이어그램 렌더링 등) 컴퓨터에 아래 환경이 갖춰져 있어야 합니다.
- **Python 및 Node.js 설치**: 스크립트 실행을 위해 필수입니다.
- **필수 패키지 설치**: 터미널(명령 프롬프트)에서 아래 명령어를 실행하여 필수 라이브러리를 설치해 주세요.
  ```bash
  pip install python-pptx playwright
  playwright install chromium
  ```

### 2. 스킬 설치 방법 (Installation)
설치 과정은 매우 간단합니다. 안티그래비티 대화창에 아래와 같이 링크와 함께 설치를 부탁하기만 하면 됩니다.
> *"https://github.com/kimmokdong/slide-skill 이거 설치해줘"*

AI가 스스로 저장소를 복제하여 시스템에 등록하며, 만약 위에서 언급한 필수 패키지가 없다면 AI가 실행 중 오류를 감지하고 스스로 설치를 도와주거나 안내해 줍니다.

### 3. 작동 방법 (How to Command)
가장 쉬운 방법은 **발표할 내용(텍스트)만 그냥 던져주는 것**입니다.
내용만 주셔도 AI가 똑똑하게 부족한 정보를 파악하기 위해 **다음과 같은 항목들을 먼저 역질문**한 뒤 작업을 시작합니다:
- **청중 수준**: 대상이 누구인가요? (예: 초등/중고등/교원/학부모/일반인)
- **강의 시간 및 장수**: 발표 시간이나 원하는 슬라이드 장수는 얼마인가요? (예: 15분, 10장)
- **톤앤매너**: 어떤 분위기로 작성할까요? (예: 공식적, 친근하게, 유머러스하게)
- **카테고리**: 어떤 목적의 슬라이드인가요? (예: 교과교육, 연수, 보고서, 제안서)
- **발표 환경**: 대면 발표인가요, 아니면 비대면(온라인)인가요?
- **테마 선택**: 원하는 디자인 테마가 있나요? (AI 알아서 맞춤, 귀여운 스타일, 기술적인 스타일 등)

하지만 질문 과정을 생략하고 한 번에 완벽한 결과를 얻고 싶다면, 위 내용들을 포함해 프롬프트를 작성해 보세요.
**🗣️ 추천 프롬프트 예시:**
> *"여기 교원 연수용으로 쓸 대본 텍스트가 있어. 15분 분량이고 친근한 톤으로 슬라이드를 만들어줘. 테마는 내용에 맞게 알아서 설정해주고, 중간에 적절한 도식이나 다이어그램도 추가해서 PPTX까지 뽑아줘."*

> [!TIP]
> **입력하는 내용이 구체적일수록 결과물이 훨씬 좋아집니다!**
> 단순히 "AI 교육에 대해 발표할거야"라고 하기보다는, 선생님이 강조하고 싶은 핵심 메시지나 실제 사례, 구체적인 예시들을 텍스트에 풍부하게 담아줄수록 AI가 원래 의도에 딱 맞는 완성도 높은 슬라이드를 기획할 확률이 높아집니다.

### 4. 무엇이 만들어지나요? (Output)
명령을 내리면 AI가 자동으로 다음 항목들을 생성합니다.
- **기승전결 구조화**: 텍스트를 요약하고 발표에 맞는 목차 구조를 기획합니다.
- **실시간 수정 가능한 웹 슬라이드(HTML)**: 브라우저에서 바로 내용을 고치거나 이미지를 넣을 수 있는 프리뷰 화면(로컬 서버)을 띄워 줍니다.
- **최종 발표용 PPTX**: 깨짐 없는 고해상도의 와이드 PPTX 파일로 캡처 및 병합하여 저장해 줍니다.

## ✨ 주요 특징 (Features)

- **단일 진실 원천 (SSOT)**: 모든 슬라이드 구조와 내용은 `slide_plan.json` 하나에서 완벽하게 제어되며, 스크립트가 이를 HTML/PPTX로 렌더링합니다.
- **반응형 유동 레이아웃 (Autofit)**: 브라우저 DOM 렌더링 스펙을 이용해 내용 길이에 따라 스스로 글자 크기를 조절하여 화면 밖으로 글씨가 튀어나가는 것을 방지합니다.
- **60-30-10 동적 테마 시스템**: 발표 주제를 분석해 AI가 스스로 가장 어울리는 배경색, 텍스트색, 포인트 강조색을 배합합니다.
- **실시간 테마 & 레이아웃 에디터**: 로컬 서버 리뷰 모드에서 슬라이드 순서 변경, 텍스트 직접 편집, 실시간 테마 변경(색상, 폰트, 패턴 등)을 수행하고 `slide_plan.json`에 즉시 저장할 수 있습니다.
- **로컬 이미지 다이렉트 업로드**: 리뷰 모드에서 이미지 프레임을 클릭하여 PC에 있는 이미지(PNG, JPG, WebP 등)를 손쉽게 업로드하고 슬라이드에 삽입할 수 있습니다.
- **드래그 앤 드롭 플로팅 UI**: 발표나 화면을 가리지 않도록, 자유롭게 이동할 수 있는 에디터/타이머 플로팅 버튼을 제공합니다.
- **정보 무손실 원칙**: 슬라이드 화면에는 핵심 키워드만 압축해 보여주고, 길고 자세한 원문은 100% '발표자 노트(Speaker Notes)' 영역으로 안전하게 보존합니다.
- **완벽한 시각적 렌더링 보존 (통이미지 PPTX)**: 네이티브 도형 변환 시 발생하는 레이아웃 깨짐을 방지하기 위해, 웹 엔진이 그려낸 완벽한 HTML을 고해상도로 캡처하여 와이드 비율의 통이미지 PPTX로 납품합니다.

## 📋 핵심 워크플로우 (Workflow)

1. **사전 컨텍스트 분석**: 텍스트, 강의 대상, 발표 환경(대면/비대면), 테마 등을 `slide_context.yaml`에 수집
2. **리서치 및 팩트체크**: 필요한 경우 외부 통계 및 레퍼런스를 검색하여 근거 보강
3. **모드 분기 및 서사 구조화**: 제안서(Fidelity 보존) 혹은 강의 원고(Summary 압축) 모드로 분기
4. **Deck Planner (`slide_plan.json` 작성)**: 적절한 다이어그램, 퀴즈, 매트릭스 등의 전용 레이아웃을 매핑하여 SSOT 설계도 작성
5. **에셋 생성**: Mermaid 도식 및 AI 이미지 에셋 추출
6. **HTML 렌더링 및 로컬 리뷰**: `build_html.py` 및 로컬 프리뷰 서버(`dev_server.py`)를 가동하여 브라우저에서 직접 내용을 수정하고 테마와 이미지를 업로드하며 검수
7. **최종 통이미지 PPTX 추출**: HTML 화면을 캡처(`capture_png.py`)하고 와이드 통이미지 PPTX로 병합(`export_image_pptx.py`)

## 🛠️ 내부 스크립트 도구들 (`scripts/`)

- `build_html.py` : JSON을 읽어 HTML 페이지를 렌더링합니다.
- `dev_server.py` : 로컬 개발 프리뷰 서버를 가동합니다.
- `render_mermaid.py` : Mermaid 문법을 파싱해 SVG 도식을 생성합니다.
- `parse_pdf.py` / `parse_pptx.py` : 레퍼런스 문서를 텍스트로 추출합니다.
- `capture_png.py` : 완성된 HTML 화면을 고해상도 PNG로 캡처합니다.
- `export_image_pptx.py` : 캡처된 슬라이드 이미지들을 하나의 와이드 PPTX 파일로 병합합니다.
